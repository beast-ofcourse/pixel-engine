## Findings considered and rejected

- **Monolithic HD scene (single 1280×720 scene document)**: rejected — LLM context blow-up and forgetting make a single HD JSON infeasible; tiled composition (002) is the viable path. A single large canvas would also break all hash-locked square-scene tests.
- **Learned aesthetic reward model (train a scorer on human preferences)**: rejected for now — requires human-signal data that does not yet exist; the codifiable craft checks (Phase 5) plus the critic loop (003) are the prerequisite. Revisit after 003 has produced labeled PASS/FAIL examples.
- **Full auto-vectorization (raster → poly tracing)**: rejected as a build-everything plan — it is a multi-month computer-vision project; 004's scaffolded import (palette + empty layers + reference buffer) gives 80% of the value with the LLM doing the tracing.
- **Switching from JSON scene docs to a binary format**: rejected — JSON is human-readable, diffable, and git-friendly; 001's compact JSON (short keys + palette indices + flat points) achieves the token saving without losing those properties. Binary would add tooling cost for little extra saving.
